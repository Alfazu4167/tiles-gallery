# 🗺️ Tiles Gallery

A modern web application built with **Next.js** and integrated with **Google OAuth** for seamless user authentication. Users can view, explore, and interact with a curated gallery of tiles.

🔗 **Live Demo:** https://tiles-gallery-gules.vercel.app

---

## 🚀 Features

- **Google Authentication:** Secure login using Google OAuth via NextAuth.js.
- **Dynamic Gallery:** Clean and responsive UI showcasing various tile designs.
- **Vercel Deployment:** Optimized for fast loading and edge hosting.
- **Responsive Design:** Fully functional across mobile, tablet, and desktop screens.

---

## 🛠️ Tech Stack

- **Framework:** Next.js (App Router)
- **Authentication:** BetterAuth
- **Styling:** Tailwind CSS
- **Deployment:** Vercel
